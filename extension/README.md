# City Workspaces (Chrome extension)

Saves your open tabs into your isocity workspaces, like Workona.

Install: open `chrome://extensions`, turn on Developer mode, click "Load unpacked", pick this `extension` folder.

- Save all tabs / Save this tab: adds them to the chosen workspace (optionally closes them).
- Open workspace: opens every saved link in a new window.
- Suspend other tabs: frees memory from tabs you are not using.
- Alt+W opens the popup, Alt+Shift+S saves the current window.
- Syncs with the city (isocity-mu.vercel.app) whenever it is open; the newest change wins.
